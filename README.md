### Featured Projects

**[Lente Democrática](https://lente-democratica.vercel.app)** — React 18 + Vite + Supabase + Python + PostgreSQL
What your party promised, and how it actually voted. Five official sources from the Spanish Congress normalised into one schema. The vote JSONs identify deputies by name only, so identity resolution runs as a cascade: alias, then trigrams, then an LLM, then a human review queue. The ideological map ships with a permutation test.
→ [Live Demo](https://lente-democratica.vercel.app)

**[Zolarium](https://zolariumapp.com)** — React 19 + Vite + Supabase + PWA / TWA
An archetype app that works offline and ships on Google Play. The recommendation engine runs on the device and retrains itself from swipes through a Postgres function. Initial bundle cut from 426 kB to 259 kB with route-level code splitting.
→ [Live Demo](https://zolariumapp.com) | [Repository](https://github.com/MarcosJVPR/Zolarium)

**[PYME Copilot](https://ai-for-small-businesses.vercel.app)** — React + Vite + pgvector + Supabase
Upload your company documents and ask. Every answer cites its source. Chunking with overlap, embeddings, and semantic search over pgvector inside Postgres rather than a separate vector database. If the answer is not in your documents, it says so.
→ [Live Demo](https://ai-for-small-businesses.vercel.app)

**Travel to Spain** — React + Vite + Tailwind
Real Spanish Tourism API (Dataestur) integration with interactive data visualization and per-destination color themes. The API returns Excel, not JSON: a serverless proxy solves CORS and SheetJS parses 43,768 rows in the browser.
→ [Live Demo](https://travel-to-spain.vercel.app/) | [Repository](https://github.com/MarcosJVPR/TravelToSpain)

**Hadas Vs Ogros** — Unreal Engine 5 (Blueprints)
Asymmetric 3D RTS in development. The Sylvan Court vs. The Iron-Crag Clans with era progression, dynamic biomes, and faction-specific visuals. Solo developer, Blueprints-only architecture.
